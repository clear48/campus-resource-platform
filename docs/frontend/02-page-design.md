# 校园资料共享与智能检索平台页面设计文档

## 1. 文档目标

本文档基于 `docs/frontend/01-frontend-requirements.md`、`docs/api/api-reference.md` 和当前后端 DTO/VO，进一步定义前端各页面的路由、访问角色、功能、接口、展示字段、按钮与操作。

页面设计只服务于后端功能演示和接口联调，优先保证业务链路清晰、操作结果可见、技术亮点容易讲解。首版使用简单表单、表格、列表、标签、弹窗和消息提示即可，不追求复杂 UI、复杂动画、复杂图表或商业产品级交互。

## 2. 页面设计总则

| 设计项 | 首版约定 |
| --- | --- |
| 页面布局 | 顶部导航 + 主内容区；管理员页面可增加简单左侧固定菜单 |
| 导航方式 | 使用固定路由，不使用后端动态菜单和动态路由 |
| 页面组件 | 表单、表格、分页、状态标签、确认弹窗、抽屉或普通弹窗 |
| 登录态 | 保存 JWT 和当前用户基本信息，受保护请求携带 Bearer Token |
| 权限展示 | 根据登录状态和 `role` 简单显示入口；最终权限以后端校验为准 |
| 列表状态 | 加载中、空数据、加载失败、分页、操作成功提示 |
| 错误展示 | 展示后端 `message`；开发演示模式可同时展示 `traceId` |
| 文件下载 | 先创建下载记录，再使用返回的下载记录 ID 请求二进制文件流 |
| 数据格式 | 时间统一格式化为 `YYYY-MM-DD HH:mm:ss`；数量无数据时显示 `0` |
| 状态展示 | 使用文本标签，不使用复杂流程图或动画 |
| UI 范围 | 以桌面端演示为主，只做基础自适应，不建设复杂主题系统 |

## 3. 页面总览

| 页面 | 路由 | 用户角色 | 页面主要功能 | 主要接口 |
| --- | --- | --- | --- | --- |
| 登录页 | `/login` | 游客 | 登录并获取 JWT | `POST /api/v1/auth/login`、`GET /api/v1/users/me` |
| 注册页 | `/register` | 游客 | 创建普通用户账号 | `POST /api/v1/auth/register` |

| 资料搜索页 | `/search` | 游客、普通用户、管理员 | 搜索、筛选和排序公开资料 | 分类接口、资料搜索接口 |
| 资料详情页 | `/resources/:id` | 游客、普通用户、管理员 | 查看详情、收藏和下载 | 详情、收藏、下载接口 |
| 上传资料页 | `/upload` | 普通用户、管理员 | MD5 预检、文件上传、创建资料 | 分类、文件和资料创建接口 |

| 我的下载页 | `/me/downloads` | 普通用户、管理员 | 查看本人下载记录并再次下载 | 下载记录列表、文件流接口 |
| 个人信息页 | `/me/profile` | 普通用户、管理员 | 查看当前用户并退出登录 | 当前用户、退出接口 |
| 审核管理页 | `/admin/reviews` | 管理员 | 审核通过、拒绝和查看流水 | 管理员审核接口 |
| 发布资料管理页 | `/admin/resources` | 管理员 | 搜索已发布资料并下架 | 搜索、详情、下架、审核流水接口 |
| 排行榜运维页 | `/admin/rankings` | 管理员 | 查看榜单并手动重建总榜 | 排行榜查询、管理员重建接口 |

## 4. 公共与普通用户页面

### 4.1 登录页

#### 页面基本信息

| 项目 | 设计 |
| --- | --- |
| 路由 | `/login` |
| 用户角色 | 游客；已登录用户访问时可直接跳转首页 |
| 页面功能 | 提交账号密码、获取 JWT、识别用户角色、恢复当前用户信息 |
| 使用接口 | `POST /api/v1/auth/login`；登录成功后可调用 `GET /api/v1/users/me` 校验并恢复用户信息 |
| 简单布局 | 居中登录表单 + 注册入口 + 错误提示区域 |

#### 字段设计

| 区域 | 字段 | 来源/提交字段 | 展示或输入要求 |
| --- | --- | --- | --- |
| 登录表单 | 用户名 | `username` | 必填文本框 |
| 登录表单 | 密码 | `password` | 必填密码框 |
| 登录结果 | Access Token | `accessToken` | 默认不直接展示；开发演示模式可脱敏展示 |
| 登录结果 | Token 类型 | `tokenType` | 可在开发信息区展示 |
| 登录结果 | 有效时间 | `expiresIn` | 转换为秒或分钟展示 |
| 登录结果 | 用户 ID | `user.userId` | 登录成功后保存 |
| 登录结果 | 用户名 | `user.username` | 顶部导航可展示 |
| 登录结果 | 昵称 | `user.nickname` | 顶部导航优先展示 |
| 登录结果 | 邮箱 | `user.email` | 保存到当前用户信息 |
| 登录结果 | 角色 | `user.role` | `1` 普通用户，`2` 管理员 |
| 登录结果 | 账号状态 | `user.status` | 用文本标签展示 |
| 错误信息 | 消息、追踪 ID | `message`、`traceId` | 登录失败时展示；追踪 ID仅用于演示与排错 |

#### 按钮与操作

| 按钮/操作 | 触发条件 | 处理逻辑 | 成功结果 | 失败处理 |
| --- | --- | --- | --- | --- |
| 登录 | 用户名和密码已填写 | 调用登录接口，提交期间禁用按钮 | 保存 JWT 和用户信息；管理员跳转 `/admin/reviews`，其他用户跳转 `/` | 展示后端错误消息 |
| 前往注册 | 始终可用 | 跳转 `/register` | 显示注册页 | 无 |
| 显示/隐藏密码 | 密码框有内容 | 切换输入框类型 | 仅改变本地显示 | 无 |

### 4.2 注册页

#### 页面基本信息

| 项目 | 设计 |
| --- | --- |

| 用户角色 | 游客 |

| 字段 | 提交字段 | 类型 | 展示或输入要求 |
| --- | --- | --- | --- |

| 密码 | `password` | 密码框 | 必填；前端只做基础格式提示 |
| 昵称 | `nickname` | 文本框 | 必填 |
| 邮箱 | `email` | 邮箱输入框 | 必填；基础邮箱格式校验 |
| 手机号 | `phone` | 文本框 | 按 API 约定填写 |
| 注册结果 | `message` | 提示消息 | 注册成功或失败后展示 |
| 追踪 ID | `traceId` | 文本 | 仅失败且处于开发演示模式时展示 |

#### 按钮与操作

| 按钮/操作 | 触发条件 | 处理逻辑 | 成功结果 | 失败处理 |
| --- | --- | --- | --- | --- |
| 注册 | 必填项通过基础校验 | 调用注册接口，防止重复提交 | 提示注册成功并跳转 `/login` | 展示参数错误或重复账号提示 |
| 清空 | 表单有内容 | 清空当前表单 | 恢复初始状态 | 无 |
| 返回登录 | 始终可用 | 跳转 `/login` | 显示登录页 | 无 |

### 4.3 首页

#### 页面基本信息

| 项目 | 设计 |
| --- | --- |
| 路由 | `/` |
| 用户角色 | 游客、普通用户、管理员 |
| 页面功能 | 快速搜索、查看热门资料、查看热门搜索词 |
| 使用接口 | `GET /api/v1/rankings/resources/hot`；`GET /api/v1/rankings/search-keywords/hot` |
| 简单布局 | 顶部搜索框 + 热门资料表格/列表 + 热门搜索词列表 |

#### 字段设计

| 区域 | 字段 | 接口字段 | 展示要求 |
| --- | --- | --- | --- |
| 快速搜索 | 搜索关键词 | 本地输入 | 输入后跳转搜索页，不在首页直接请求搜索接口 |
| 热门资料 | 名次 | `rank` | 显示数字名次 |
| 热门资料 | 资料 ID | `resourceId` | 默认不突出展示，可用于跳转详情 |
| 热门资料 | 标题 | `title` | 可点击进入详情 |
| 热门资料 | 课程名称 | `courseName` | 普通文本 |
| 热门资料 | 下载量 | `downloadCount` | 数字展示 |
| 热门资料 | 收藏量 | `favoriteCount` | 数字展示 |
| 热门资料 | 热度分 | `hotScore` | 数字展示，不绘制复杂图表 |
| 热门搜索词 | 名次 | `rank` | 显示数字名次 |
| 热门搜索词 | 关键词 | `keyword` | 可点击发起搜索 |
| 热门搜索词 | 搜索次数 | `searchCount` | 数字展示 |
| 榜单条件 | 周期 | 请求参数 `period` | 资料榜支持 `daily/weekly/monthly/all`；热词榜支持 `daily/weekly/monthly` |

#### 按钮与操作

| 按钮/操作 | 触发条件 | 处理逻辑 | 结果 |
| --- | --- | --- | --- |
| 搜索 | 输入关键词或允许空关键词 | 跳转 `/search?keyword={keyword}` | 搜索页执行真实搜索 |
| 切换资料榜周期 | 点击日/周/月/总榜 | 重新请求热门资料接口 | 刷新资料榜列表 |
| 切换热词榜周期 | 点击日/周/月榜 | 重新请求热门搜索词接口 | 刷新热词列表 |
| 点击资料标题 | 资料 ID 有效 | 跳转 `/resources/{resourceId}` | 显示资料详情 |
| 点击热门搜索词 | 关键词有效 | 跳转 `/search?keyword={keyword}` | 显示对应搜索结果 |
| 重试 | 榜单请求失败 | 重新请求失败的榜单接口 | 恢复列表或继续显示错误 |

### 4.4 资料搜索页

#### 页面基本信息

| 项目 | 设计 |
| --- | --- |
| 路由 | `/search` |
| 用户角色 | 游客、普通用户、管理员 |
| 页面功能 | 按多条件搜索、筛选、排序和分页浏览已审核通过资料 |
| 使用接口 | `GET /api/v1/categories`；`GET /api/v1/search/resources` |
| 简单布局 | 顶部筛选表单 + 结果表格/卡片列表 + 分页器 |

#### 查询字段设计

| 页面字段 | 请求参数 | 输入形式 | 说明 |
| --- | --- | --- | --- |
| 关键词 | `keyword` | 文本框 | 可为空；非空搜索成功后后端记录热门搜索词 |
| 分类 | `categoryId` | 简单下拉框 | 选项来自分类接口 |
| 课程名称 | `courseName` | 文本框 | 可选 |
| 资料类型 | `resourceType` | 固定枚举下拉框 | 显示中文名称，提交整数值 |
| 标签 | `tag` | 文本框 | 首版不做复杂标签选择器 |
| 排序字段 | `sortBy` | 下拉框 | `createdAt/downloadCount/favoriteCount/hotScore` |
| 排序方向 | `order` | 下拉框 | `asc/desc` |
| 页码 | `pageNo` | 分页器 | 默认第 1 页 |
| 每页数量 | `pageSize` | 简单下拉框 | 使用后端允许的范围 |

#### 结果字段设计

| 字段 | 接口字段 | 展示要求 |
| --- | --- | --- |
| 资料 ID | `records[].resourceId` | 用于详情跳转，可不单独显示 |
| 标题 | `records[].title` | 主列，可点击 |
| 简介 | `records[].description` | 最多显示两到三行，超出省略 |
| 课程名称 | `records[].courseName` | 普通文本 |
| 资料类型 | `records[].resourceType` | 转换为中文标签 |
| 标签 | `records[].tags` | 使用简单标签逐项展示 |
| 下载量 | `records[].downloadCount` | 数字展示 |
| 收藏量 | `records[].favoriteCount` | 数字展示 |
| 热度分 | `records[].hotScore` | 数字展示 |
| 创建时间 | `records[].createdAt` | 格式化时间 |
| 当前页 | `pageNo` | 分页器使用 |
| 每页数量 | `pageSize` | 分页器使用 |
| 总记录数 | `total` | 显示在分页区域 |
| 总页数 | `pages` | 分页器使用 |

#### 按钮与操作

| 按钮/操作 | 处理逻辑 | 结果 |
| --- | --- | --- |
| 搜索 | 重置到第 1 页并调用搜索接口 | 显示匹配的公开资料 |
| 重置 | 清空筛选项并恢复默认排序 | 重新加载默认公开列表 |
| 切换排序 | 更新 `sortBy/order` 后重新请求 | 后端按白名单字段排序 |
| 查看详情 | 跳转 `/resources/{resourceId}` | 打开资料详情页 |
| 翻页 | 更新 `pageNo/pageSize` | 加载对应分页数据 |
| 重试 | 重新执行最近一次查询 | 恢复结果或继续显示错误 |

首版不展示搜索建议下拉框，因为 `GET /api/v1/search/suggestions` 尚未实现。

### 4.5 资料详情页

#### 页面基本信息

| 项目 | 设计 |
| --- | --- |
| 路由 | `/resources/:id` |
| 用户角色 | 游客可查看；普通用户和管理员登录后可收藏、取消收藏和下载 |
| 页面功能 | 查看公开资料详情，执行收藏与两步下载 |
| 使用接口 | `GET /api/v1/resources/{resourceId}`；`GET /api/v1/resources/{resourceId}/favorite-status`；`POST /api/v1/resources/{resourceId}/favorites`；`DELETE /api/v1/resources/{resourceId}/favorites`；`POST /api/v1/resources/{resourceId}/download-records`；`GET /api/v1/download-records/{downloadRecordId}/file` |
| 简单布局 | 资料信息区 + 统计信息区 + 操作按钮区 |

#### 展示字段设计

| 字段 | 接口字段 | 展示要求 |
| --- | --- | --- |
| 资料 ID | `resourceId` | 可放在开发信息区 |
| 标题 | `title` | 页面主标题 |
| 简介 | `description` | 普通多行文本 |
| 分类 ID | `categoryId` | 默认不突出显示 |
| 分类名称 | `categoryName` | 文本或简单标签 |
| 课程名称 | `courseName` | 普通文本 |
| 资料类型 | `resourceType` | 转换为中文标签 |
| 标签 | `tags` | 简单标签列表 |
| 资料状态 | `status` | 公开详情正常应为已通过 |
| 下载量 | `downloadCount` | 数字展示 |
| 收藏量 | `favoriteCount` | 数字展示；收藏操作后按接口结果刷新 |
| 热度分 | `hotScore` | 数字展示 |
| 创建时间 | `createdAt` | 格式化时间 |
| 是否已收藏 | `favorited` 或收藏状态接口的 `favorited` | 控制收藏按钮文字和状态 |
| 下载记录 ID | `downloadRecordId` | 创建下载记录后内部保存，不必长期展示 |
| 本次是否计数 | `counted` | 可用简短提示演示下载去重 |

#### 按钮与操作

| 按钮/操作 | 用户条件 | 调用接口/处理逻辑 | 结果 |
| --- | --- | --- | --- |
| 收藏 | 已登录且当前未收藏 | `POST /api/v1/resources/{resourceId}/favorites` | 更新收藏状态和收藏数 |
| 取消收藏 | 已登录且当前已收藏 | `DELETE /api/v1/resources/{resourceId}/favorites` | 更新收藏状态和收藏数 |
| 下载 | 已登录 | 先调用创建下载记录接口，再调用返回的 `downloadUrl` 或文件流接口 | 浏览器保存文件；提示本次是否计数 |
| 登录后操作 | 游客点击收藏或下载 | 跳转 `/login`，可保留返回地址 | 登录后返回详情页 |
| 返回搜索 | 始终可用 | 返回上一页或 `/search` | 回到资料列表 |
| 重试 | 详情加载失败 | 重新请求详情接口 | 恢复页面或继续显示错误 |

### 4.6 上传资料页

#### 页面基本信息

| 项目 | 设计 |
| --- | --- |
| 路由 | `/upload` |
| 用户角色 | 普通用户、管理员 |
| 页面功能 | 选择文件、计算 MD5、执行秒传预检、上传物理文件、创建待审核资料 |
| 使用接口 | `GET /api/v1/categories`；`GET /api/v1/files/check`；`POST /api/v1/files`；`POST /api/v1/resources` |
| 简单布局 | 文件区域 + 资料元数据表单 + 分步执行状态 |

#### 输入与过程字段设计

| 区域 | 字段 | 请求/响应字段 | 展示或输入要求 |
| --- | --- | --- | --- |
| 文件选择 | 文件 | multipart `file` | 单文件选择 |
| 文件信息 | 原始文件名 | `originalName` | 选择后展示 |
| 文件信息 | 文件大小 | `fileSize` | 格式化为 KB/MB |
| 文件信息 | 文件扩展名 | `fileExt` | 上传结果中展示 |
| MD5 预检 | 文件 MD5 | `fileMd5` | 展示计算结果或缩略值 |
| MD5 预检 | 是否秒传 | `secondUpload` | 命中时显示“复用已有文件” |
| 文件结果 | 文件 ID | `fileId` | 创建资料时必须提交；可在步骤结果中展示 |
| 资料表单 | 标题 | `title` | 必填 |
| 资料表单 | 简介 | `description` | 多行文本 |
| 资料表单 | 分类 | `categoryId` | 选项来自分类接口 |
| 资料表单 | 课程名称 | `courseName` | 必填 |
| 资料表单 | 资料类型 | `resourceType` | 固定枚举下拉框 |
| 资料表单 | 标签 | `tags` | 简单逗号输入或可添加标签；提交数组 |
| 创建结果 | 资料 ID | `resourceId` | 成功后展示 |
| 创建结果 | 状态 | `status`、`statusName` | 显示“待审核” |

| 普通用户访问 `/admin/**` | 提示权限不足并返回首页 | 管理接口仍由 Service 校验管理员角色 |
| Token 失效或被拉黑 | 清理本地登录态并跳转登录 | 后端返回 `40101/40102` |
| 后端返回 `40301` | 显示权限不足 | 不依赖前端隐藏菜单保障安全 |

## 7. 状态、枚举与通用字段展示

### 7.1 资料状态

| 状态值 | 展示文本 | 建议简单样式 | 可执行操作 |
| --- | --- | --- | --- |
| `0` | 待审核 | 黄色标签 | 管理员可通过或拒绝 |
| `1` | 已通过 | 绿色标签 | 可公开查看、收藏、下载；管理员可下架 |
| `2` | 已拒绝 | 红色标签 | 仅在我的上传中查看原因 |
| `3` | 已下架 | 灰色标签 | 仅在我的上传中查看原因 |
| `4` | 已删除 | 灰色标签 | 首版无前端操作 |

### 7.2 通用分页字段

| 字段 | 用途 | 页面处理 |
| --- | --- | --- |
| `records` | 当前页记录 | 绑定表格或列表 |
| `pageNo` | 当前页码 | 绑定分页器 |
| `pageSize` | 每页数量 | 绑定分页器 |
| `total` | 总记录数 | 显示总数 |
| `pages` | 总页数 | 控制翻页范围 |

### 7.3 统一响应字段

| 字段 | 用途 | 页面处理 |
| --- | --- | --- |
| `code` | 业务状态码 | `0` 为成功，其他值进入错误处理 |
| `message` | 结果说明 | 成功或失败提示 |
| `data` | 业务数据 | 渲染页面字段 |
| `traceId` | 请求追踪标识 | 开发演示模式下用于排错展示 |

文件流接口不使用上述 JSON 响应结构，前端应单独按二进制响应处理。

## 9. 页面设计验收标准

| 验收项 | 标准 |
| --- | --- |
| 页面覆盖 | 10 个公共/普通用户页面和 3 个管理员页面均有明确设计 |
| 路由 | 每个页面都有固定路由和访问角色 |
| 接口 | 每个页面只使用当前已实现的后端接口 |
| 字段 | 每个页面明确输入字段、展示字段及字段来源 |
| 操作 | 每个页面明确按钮、触发条件、调用逻辑和结果 |
| 权限 | 游客、普通用户、管理员入口清晰，真实权限以后端为准 |
| 状态 | 加载、空数据、失败、分页和提交中状态可处理 |
| 下载 | 能正确执行创建下载记录和获取文件流两步操作 |
| 审核 | 能演示待审核、通过、拒绝和下架状态流转 |
| 后端亮点 | 页面操作能够覆盖 JWT、MD5 秒传、审核事务、收藏缓存、下载限流和排行榜 |
| UI 范围 | 使用基础表格、表单、标签和弹窗，不引入复杂 UI 与复杂图表 |
