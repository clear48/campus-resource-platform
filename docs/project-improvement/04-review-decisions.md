## 状态说明

- `PROPOSED`：已提出，尚未获得实施许可。
- `APPROVED`：用户明确批准，可在批准范围内实施。
- `NEEDS_REVISION`：方向可继续讨论，但方案、范围或验收条件需要修改。
- `REJECTED`：明确不实施。
- `DEFERRED`：认可问题但延期，需记录恢复审核条件或日期。

填写规则：只有用户能把当前决定改为非 `PROPOSED`；“允许修改的文件”必须是明确路径/目录，“禁止修改的内容”优先于批次建议；未填写允许范围时不得进入实现阶段。
